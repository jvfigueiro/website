UltimateLab

Um pouco sobre o meu home lab e as tecnologias utilizadas. Um pequeno cluster de virtualização baseado no Proxmox VE, distribuído entre mini PCs, para orquestração de serviços de DNS, VPN, automação residencial e inferência de IA local — incluindo este site.

UltimateTV

Aplicação de IPTV que funciona como um front-end para o Dispatcharr, destinada ao uso exclusivo em redes locais e projetada para proporcionar uma experiência de uso semelhante à da TV tradicional.

RetroNask

Aplicação de emulação de videogames retrô feita para rodar diretamente via navegador, baseada em EmulatorJS e Ruffle. Concebida para ser uma plataforma extremamente leve tanto para o servidor que hospeda quanto para o cliente que executa.

Legacy Mac Boost

Script desenvolvido para otimizar a performance de Macs antigos rodando as últimas versões do macOS via OCLP (OpenCore Legacy Patcher), voltado para máquinas utilizadas em redes isoladas.

Upgrade de ECU Ford

Uma aventura que começou como uma tentativa via Arduino de decodificar o protocolo proprietário DCL presentes em módulos de injeção eletrônica Ford EEC-IV. Mas a falta de documentação confiável levou a uma troca completa de módulo por uma EEC-V — e hoje alimenta telemetria de motor em tempo real para automação preditiva no Home Assistant.

Monitoramento de temperatura e umidade usando sensores DHT11 ligados à um Arduino Mega. Os dados são repassados via interface serial para o Home Assistant virtualizado no Proxmox, alimentando rotinas de automação climática.
